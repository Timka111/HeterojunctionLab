# HeterojunctionLab

**HeterojunctionLab** — кроссплатформенное приложение на C++ и Qt для численного расчета параметров и визуализации энергетических зонных диаграмм полупроводниковых гетероструктур на основе правила электронного сродства (модели Андерсона).

Программа предназначена для моделирования гетеропереходов на основе произвольных полупроводниковых материалов, исследования распределения потенциала и контактной разности, определения параметров области пространственного заряда (ОПЗ), а также построения равновесных зонных диаграмм до контакта и после формирования гетероперехода.

---

## Основные возможности

* **Универсальная параметризация материалов:**
  * Ширина запрещенной зоны $E_g$ (эВ).
  * Электронное сродство $\chi$ (эВ).
  * Концентрация примеси $N_a$ ($N_d$) (см$^{-3}$).
  * Эффективные массы носителей заряда: дырок $m_h$ и электронов $m_e$ (в единицах массы покоя электрона $m_0$).
  * Статическая диэлектрическая проницаемость $\varepsilon$.
  * Рабочая температура $T$ (К).
* **Встроенная база полупроводников:**
  * Предустановленные профили параметров для распространенных полупроводниковых соединений: $\text{InP}$, $\text{Cu}_2\text{O}$, $\text{GaAs}$, $\text{Si}$, $\text{Ge}$, $\text{GaN}$, $\text{CdTe}$, $\text{ZnS}$, $\text{InAs}$, $\text{AlAs}$.
  * Режим свободного ввода параметров для любых экспериментальных материалов и твердых растворов.
* **Аналитический расчет физических величин:**
  * Разрывы краев зон: зоны проводимости $\Delta E_c$, запрещенной зоны $\Delta E_g$ и валентной зоны $\Delta E_v$.
  * Эффективные плотности квантовых состояний в валентной зоне $N_V$ и зоне проводимости $N_c$.
  * Глубина залегания уровня Ферми относительно потолка валентной зоны $q\phi$.
  * Диффузионный (контактный) потенциал $\phi_0$.
  * Полная ширина ОПЗ $X_d$ и толщины слоев обеднения в каждом из контактирующих материалов $x_{d1}, x_{d2}$.
  * Падения потенциала в слоях гетероперехода $q\phi_{01}$ и $q\phi_{02}$ с контролем баланса потенциалов.
* **Интерактивный графический модуль:**
  * График 1: Равновесная энергетическая диаграмма сформированного гетероперехода (уровень вакуума $E_0(x)$, дно зоны проводимости $E_c(x)$, потолок валентной зоны $E_v(x)$, единый уровень Ферми $E_F$) с учетом параболического изгиба зон в ОПЗ.
  * График 2: Энергетическая диаграмма изолированных полупроводников до образования контакта (относительно общего вакуумного уровня $E_0 = 0$).
  * Цветовое зонирование ОПЗ, маркировка границы металлургического контакта $x=0$, адаптивная координатная сетка.
  * Инструмент отслеживания координат $(x, E)$ при наведении курсора мыши.
  * Экспорт диаграмм в растровые форматы высокой четкости (PNG, JPG, BMP).

## Теоретическая база

Расчет зонной структуры основывается на модели Андерсона:

1. **Разрывы энергетических зон:**
   $$\Delta E_c = \chi_1 - \chi_2$$
   $$\Delta E_g = |E_{g1} - E_{g2}|$$
   $$\Delta E_v = |\Delta E_g - \Delta E_c|$$

2. **Эффективная плотность состояний:**
   $$N_{V,c} = \frac{2 (2\pi m_{h,e}^* k_B T)^{3/2}}{h^3}$$

3. **Положение уровня Ферми в нейтральной области:**
   $$q\phi = \frac{k_B T}{q} \ln\left(\frac{N_V}{N_a}\right)$$

4. **Контактная разность потенциалов:**
   $$\phi_0 = E_{g1} - E_{g2} + \Delta E_c - q\phi_1 + q\phi_2$$

5. **Ширина области пространственного заряда:**
   $$X_d = \sqrt{\frac{2 \varepsilon_0 \phi_0 (N_{a1} + N_{a2})^2}{q N_{a1} N_{a2} \left(\frac{N_{a1}}{\varepsilon_2} + \frac{N_{a2}}{\varepsilon_1}\right)}}$$
   $$x_{d1} = X_d \frac{N_{a2}}{N_{a1} + N_{a2}}, \quad x_{d2} = X_d \frac{N_{a1}}{N_{a1} + N_{a2}}$$

6. **Параболический профиль изгиба зон (решение уравнения Пуассона):**
   $$V_1(x) = \frac{q N_{a1} (x + x_{d1})^2}{2 \varepsilon_1 \varepsilon_0}, \quad -x_{d1} \le x \le 0$$
   $$V_2(x) = \frac{q N_{a2} (x_{d2} - x)^2}{2 \varepsilon_2 \varepsilon_0}, \quad 0 \le x \le x_{d2}$$

## Архитектура проекта

Проект разработан по модульному принципу без внешних сторонних зависимостей (только стандартная библиотека C++17 и Qt Core/Gui/Widgets):

```
HeterojunctionLab/
├── HeterojunctionLab.pro     # Сборочный сценарий qmake
├── CMakeLists.txt            # Сборочный сценарий CMake
├── main.cpp                  # Инициализация приложения и стилизация интерфейса
├── mainwindow.h / .cpp       # Главное окно: форма ввода, вкладки, таблица результатов
├── heterojunction_model.h    # Модель: физические константы, расчетные структуры и алгоритмы
├── heterojunction_model.cpp  # Численная реализация уравнений модели Андерсона
├── diagram_plot_widget.h     # Графический компонент на базе QPainter
└── diagram_plot_widget.cpp   # Отрисовка координатной сетки, кривых и зон ОПЗ
```

## Сборка и запуск

### Требования к окружению
* Компилятор с поддержкой **C++17** (GCC 8+, Clang 7+, MSVC 2017+).
* Фреймворк **Qt 5.12+** или **Qt 6.x** (модули `Core`, `Gui`, `Widgets`).

### Сборка через Qt Creator (рекомендуется)
1. Откройте **Qt Creator**.
2. Выберите меню `Файл` $\rightarrow$ `Открыть файл или проект...` и укажите `HeterojunctionLab.pro` (или `CMakeLists.txt`).
3. Настройте комплект сборки (Kit) и нажмите `Ctrl + R` для сборки и запуска.

### Сборка через терминал (qmake)
```bash
cd HeterojunctionLab
qmake HeterojunctionLab.pro
make -j$(nproc)       # На Windows: mingw32-make или nmake
./HeterojunctionLab   # На Windows: .\HeterojunctionLab.exe
```

### Сборка через терминал (CMake)
```bash
cd HeterojunctionLab
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
./build/HeterojunctionLab
```
